# 口播剪辑评价细则

## 评价边界

| 计入剪辑评价 | 不计入剪辑评价 |
|---|---|
| 景别、构图、跳剪、A/B-roll、转场 | 人物长相、穿搭、魅力、口才 |
| 切点时机、镜头节奏、停顿压缩 | 讲话内容是否正确、是否有价值 |
| 字幕、标题、图形、动画、贴纸 | 人物音色是否好听 |
| 音乐、音效、混音、淡入淡出 | 人物表演是否自然 |
| 音画同步、连续性、技术质量 | 观点是否成立 |
| 人物在画面中的位置、跳剪是否穿帮 | 单纯的播放量、完播率 |

语速、停顿、重音可以作为节奏锚点，但只评价它们对剪辑时机的影响。

## 六个固定维度

| ID | 维度 | 权重 | 核心问题 |
|---|---|---:|---|
| `rhythmAndShots` | 节奏与镜头组织 | 20% | 切得是否有动机，是否既不拖沓也不碎裂 |
| `visualSupport` | 视觉支撑与信息表达 | 20% | B-roll、演示、图表是否真正帮助理解 |
| `captionsAndGraphics` | 字幕与图形包装 | 15% | 是否可读、同步、层级清楚、不遮挡 |
| `audioEditing` | 声音剪辑与混音 | 15% | 是否有接缝、噪声、音量跳变、音乐抢戏 |
| `continuityAndTechnical` | 连续性与技术质量 | 15% | 是否有跳帧、黑帧、音画不同步、明显跳剪 |
| `loadAndStyle` | 观看负荷与风格一致性 | 15% | 是否统一、耐看、不过度刺激，也不过于单调 |

权重是知识类、观点类口播的默认值。不同品类可以调整权重，但不要修改固定六个维度，便于跨视频比较。

## 自动指标

### 镜头与节奏

| 指标 | 计算或含义 | 解释 |
|---|---|---|
| `cutsPerMinute` | 切点数 ÷ 分钟数 | 剪辑密度；过高和过低都可能是问题 |
| `averageShotDurationMs` | 总时长 ÷ 镜头数 | 平均镜头停留时间 |
| `shotDurationCv` | 镜头时长标准差 ÷ 平均值 | 太低偏单调，太高偏忽快忽慢 |
| `shortShotRatio` | 小于 1 秒的镜头占比 | 判断碎剪和视觉疲劳 |
| `longShotRatio` | 大于 5 秒的镜头占比 | 判断拖沓和静态 |
| `cutPauseAlignmentRatio` | 切点落在停顿边界 ±250ms 的比例 | 只是切点与音频边界的代理指标 |
| `visualEventsPerMinute` | 切点与运动峰值的每分钟事件数 | 视觉刷新强度，不等于质量 |

阈值应按同品类参考视频的 P25-P75 或人工基准校准。不要设置一个全平台通用的“最佳切点数”。

### 运动与视觉变化

| 指标 | 含义 | 解释 |
|---|---|---|
| `meanMotion` | 低分辨率灰度帧差的平均值 | 粗略估计画面运动量 |
| `motionP95` | 运动差分的 95 分位 | 运动高峰强度 |
| `motionCv` | 运动差分变异系数 | 运动是否忽大忽小 |
| `staticSampleRatio` | 近似静止采样占比 | 可能代表留白，也可能代表拖沓 |

运动指标不能判断“画面是否有意义”。必须看 `view_frame` 或 contact sheet。

### 音频

| 指标 | 含义 | 解释 |
|---|---|---|
| `integratedLufs` | 积分响度 | 描述整体响度，不直接评价好听与否 |
| `loudnessRangeLu` | 响度范围 | 过大可能音量不稳定 |
| `truePeakDbfs` | 真峰值 | 过高有削波风险 |
| `silenceRatio` | 静音时长占比 | 停顿和呼吸感的形式指标 |
| `pauseCount` | 检测到的静音段数量 | 不代表停顿一定好或坏 |
| `longestPauseMs` | 最长静音段 | 定位可能的空拍或断裂 |
| `avStartDeltaMs` | 音视频流起始时间差 | 流级代理，不等同于逐帧口型同步 |
| `avDurationDeltaMs` | 音视频时长差 | 可提示流级同步问题 |

不要把响度、静音比例或音乐存在当成“声音剪辑质量”。还要看接缝、削波、房间声、音乐 ducking 和音效是否服务画面。

### 技术缺陷

| 指标 | 含义 |
|---|---|
| `blackIntervalCount` | 黑帧段数量 |
| `freezeIntervalCount` | 静态段候选数量 |
| `decodeErrorCount` | 解码错误候选数量 |

静态段可能是刻意的静止画面，必须复核。黑帧、冻结、字幕越界和严重音画错位要作为硬伤处理。

## 0-4 分标准

- **0 分**：严重硬伤，基本无法正常观看；
- **1 分**：问题反复出现，明显干扰理解；
- **2 分**：合格，但有较多可感知问题；
- **3 分**：良好，基本服务表达，只有少量瑕疵；
- **4 分**：优秀，剪辑有明确设计感，且不抢内容。

### 各维度的合格线与优秀线

| 维度 | 3 分 | 4 分 |
|---|---|---|
| 节奏与镜头组织 | 多数切点有动机，偶尔拖沓或碎剪 | 节奏随重点变化，有呼吸感，几乎无无意义切点 |
| 视觉支撑与信息表达 | 关键段落有相关 B-roll、演示或图表 | 视觉不仅相关，还增加证据、结构或理解效率 |
| 字幕与图形包装 | 基本可读、同步、统一 | 层级清楚、可扫读、不遮挡，风格稳定 |
| 声音剪辑与混音 | 清楚，无明显接缝和音量跳变 | 音乐、音效、环境声融合自然，几乎听不出拼接 |
| 连续性与技术质量 | 无严重硬伤，少量小问题 | 反复检查也难发现跳变、错位或技术瑕疵 |
| 观看负荷与风格一致性 | 整体统一，没有明显干扰 | 有辨识度但不疲劳，视觉节奏与内容气质一致 |

## 剪辑动机

一个切点至少满足以下一项，才可计为有动机：

- 跟随停顿、语义段落或语气重音；
- 切换到 B-roll、演示、图表或证据；
- 改变景别、重新构图或突出细节；
- 引入字幕、标题或图形；
- 完成段落、情绪或动作转换；
- 修复画面问题。

没有明确原因的随机切、为了切而切、无遮挡的跳剪，计为无动机剪辑。

## 硬伤与扣分

硬伤独立记录，不混入六维加权分。

| 等级 | 例子 | 扣分 |
|---|---|---:|
| `critical` | 全黑、无法解码、音轨缺失、严重音画不同步 | 15 |
| `major` | 明显跳剪穿帮、字幕遮挡关键画面、爆音/长段无声 | 8 |
| `minor` | 轻微文字越界、短促接缝、轻微重复镜头 | 3 |

最终分 = 六维加权分换算到 100 分 − 硬伤扣分，限制在 0-100。

## A/B 对比流程

1. 选择同品类、近时长、同平台、同画幅的视频；
2. 每条至少看开头、主体、结尾各 30 秒，再看完整视频；
3. 正常观看判断整体顺滑度和注意力；
4. 静音看画面，判断镜头、B-roll、字幕、图形和连续性；
5. 只听声音，判断停顿、接缝、音乐、音效和音量；
6. 随机 A/B 顺序，尽量盲评；有条件的评审给 0-4 分，不只选偏好；
7. 每个扣分记录时间点和证据；
8. 证据不足时输出 `tie` 或“不可比较”，不要强行选赢家。

如果要做严格实验，使用同一段原始素材和同一段配音，让两种剪辑方式各剪一版。这样人物、内容和素材质量被控制，差异更接近剪辑本身。

## 报告契约

`write_review_report` 接收：

```json
{
  "contract": "talking-head-edit-review.v1",
  "mode": "single|pairwise",
  "summary": "结论先行",
  "winner": "A|B|tie",
  "confidence": 0.8,
  "videos": [
    {
      "label": "A",
      "path": "a.mp4",
      "analysisPath": ".edit-review/analyses/a-....json",
      "dimensions": [
        {
          "id": "rhythmAndShots",
          "score": 3,
          "note": "说明判断",
          "evidence": [
            { "video": "A", "timeSeconds": 3.2, "note": "切点与停顿的关系" }
          ]
        }
      ],
      "hardDefects": [],
      "strengths": [],
      "weaknesses": []
    }
  ],
  "limitations": []
}
```

维度必须完整包含：

`rhythmAndShots`、`visualSupport`、`captionsAndGraphics`、`audioEditing`、`continuityAndTechnical`、`loadAndStyle`。

每个维度至少一条证据；每条证据必须有说明。没有证据的判断不能写进报告。

## 必须声明的限制

- 切点由 FFmpeg scene score 估算，软转场、溶解和细微推镜可能漏检；
- B-roll、字幕、图形、构图和视觉层级必须看帧判断；
- 运动、静音、响度是代理指标，不代表审美或理解质量；
- 流级音画偏差不是逐帧口型同步；
- 静态段可能是有意的留白；
- 人工观看和同赛道基准仍然是最终校准手段。
