# Reference style fixtures

These fixtures describe the input matrix for reference-video style transfer:

- 9:16 and 16:9 references
- captions and no captions
- B-roll and no B-roll
- single-video and multi-asset user media

The repository stores only synthetic metadata here. Do not commit third-party
reference videos, audio, frames, or brand assets. Add local, user-approved
samples through the product's private fixture directory during evaluation.
