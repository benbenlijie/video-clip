# 视频剪辑验证门禁

退出码通过不等于成片通过。每轮预览和终稿都必须保留可重现的检查证据。

## 预览阶段

1. `ffprobe` 检查真实显示宽高、旋转、帧率、音频轨和时长。
2. 原片至少查看开头、中段、结尾三帧；决定字幕安全区前必须先看画面。
3. 预览至少查看三帧，并覆盖每个 B-roll 区间和一个字幕/动效高峰。
4. 检查 Hook 是否在前 3 秒内出现，镜头变化是否有语义理由，字幕是否遮挡脸。

## 终稿阶段

1. 重新生成预览后再查看，不能复用旧帧的结论。
2. `ffprobe`：必须有 H.264/H.265 视频和 AAC/PCM 音频，音视频时长差不超过 250ms。
3. `blackdetect`：不允许存在持续 300ms 以上的意外黑帧。
4. 9:16 Shorts 必须是 `1080x1920`；主片保留 brief 指定的显示方向。
5. 检查字幕、视觉事件、B-roll 计划数与实际执行数是否一致。
6. 如果使用音频归一化，保留测量结果，并把噪声放大、无法听感确认等限制写入报告。
7. 保存原片、旧版本、脚本、字幕、计划、工具日志和 QC；不要覆盖既有交付物。

## 失败条件

- 没有实际 `view_frame` 证据；
- B-roll 没有来源、许可或最终插入区间的审片帧；
- 画面中出现无法解释的占位素材、随机网络请求或未授权字体/音乐；
- 字幕与画面重复表达、遮挡脸，或关键文字超出安全区；
- 生成了原片没有提供的 CTA、事实、人物或产品画面；
- 渲染器只输出技术上可播放的文件，却没有对应编辑事件的执行证据。
