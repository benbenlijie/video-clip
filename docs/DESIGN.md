# 当前产品设计

## 总体结构

网站围绕“工作流卡片 + 阶段工作台 + 产物审阅”设计，而不是传统专业 NLE 的完整复制。

```mermaid
flowchart LR
    A[选择工作流] --> B[上传素材与品牌规则]
    B --> C[素材盘点与转录]
    C --> D[剪辑计划与 Cut List]
    D --> E[Storyboard / 低成本预览]
    E --> F[时间戳批注]
    F --> G[Claude 迭代]
    G --> H[最终渲染与 QC]
    H --> I[MP4 + 字幕 + 工程 + 日志]
```

## 页面与主要交互

### 1. 工作流首页

展示可复用的成功配方卡片，每张卡片包含：

- 适用素材；
- 输出结果；
- 默认时长和画面比例；
- 预计步骤；
- 证据等级；
- 是否需要人工复核；
- 示例产物。

首版只展示一张高优先级卡片：

**Wayne Video Editing / 一条录制变五条内容**

- 证据等级：A（作者公开流程与演示，量化收益为作者自述）；
- 输入：60–90 秒口播视频、拍摄目标、品牌规则；
- 输出：1 条主成片、3–5 条 Shorts、SRT、Cut List、批注记录和 QC 报告；
- 核心检查点：转录确认、剪辑计划确认、浏览器预览、时间戳批注、最终渲染前人工确认。

其他工作流卡片暂时作为后续模板，不进入首版主流程。

### 2. 项目设置页

- 上传原始视频和音频；
- 选择输出平台和比例；
- 选择或创建品牌规则；
- 上传 3–5 个批准样例；
- 设置字幕安全区、字体、颜色、转场和禁用项。

品牌规则最终保存为项目级 `skill.md` 或等价结构化配置，供后续任务复用。

### 3. 阶段工作台

每个阶段显示：

- 当前阶段名称和进度；
- Claude 的结构化决策；
- 调用过的工具；
- 输入与输出产物；
- 可执行的下一步；
- 失败、重试、跳过和返回上一步。

阶段必须有明确终态。模型无法判断时，保守保留并标记待审核，不继续无限探索。

### 4. Storyboard 与预览审阅

- 展示代表帧、镜头顺序和时间戳；
- 用户可以对某个时间点添加批注；
- 支持“保留/删除/重新生成/修改风格”等有限动作；
- 批注传回 Claude 时只带相关片段上下文，避免重新发送整个项目。

### 5. 结果与产物页

结果页同时展示：

- 最终 MP4；
- SRT/TXT 字幕；
- cut list；
- storyboard 和预览帧；
- Remotion/HyperFrames 源码；
- FFmpeg 命令；
- FCPXML/EDL 或其他可编辑工程；
- QC 报告和人工批注记录。

## 执行状态机

```text
created
  → inspecting
  → transcribing
  → planning
  → storyboard_ready
  → awaiting_review
  → previewing
  → awaiting_revision
  → rendering
  → qc
  → completed
```

任何阶段都可以进入 `failed`、`needs_input` 或 `cancelled`。恢复时从最近一个已确认产物继续，不重复执行已经完成的昂贵步骤。

## 技术角色分工

- **Claude Opus 5.5**：素材理解、剪辑计划、cut list、工具编排、批注处理和结果审查。
- **OpenChatCut**：项目存储、可读可撤销的时间线、MCP 工具和 Agent 工作流执行。
- **Remotion**：React/代码化场景、预览和可复现渲染。
- **HyperFrames**：HTML/CSS/Canvas 动效和适合 Agent 的特效场景。
- **FFmpeg**：媒体探测、裁切、拼接、竖屏构图、字幕烧录、音频归一化和编码。
- **Whisper/WhisperX/Parakeet**：转录和时间戳。

## MVP 边界

首版只实现：

- 三个工作流入口；
- 本地/云端临时上传；
- 转录、剪辑计划、cut list；
- 静态 storyboard 和低清预览；
- 时间戳批注；
- 一次受限的 Claude 迭代；
- MP4、SRT、日志和源码导出。

首版暂不实现：

- 多用户协作和权限；
- 模板商城；
- 自动发布平台；
- 复杂 3D 特效；
- 泛用长视频全自动剪辑；
- 无人工复核的商业交付承诺。

## 工具调用约束

- 每个阶段设置工具白名单和调用上限；
- `target_project` 每个阶段最多调用一次；
- 编辑前必须先读取当前项目状态；
- 编辑后必须再次读取项目并通过 QC；
- 工具失败三次后停止并请求用户决策；
- 不允许模型自行创建多个重复项目来“恢复状态”；
- 最终成功必须由真实产物和 QC 结果证明。
