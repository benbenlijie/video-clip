# Claude Code 驱动视频剪辑

用户已明确要求复现 Claude Code + Opus 5.5 + 工具 + skill 的工作流。

当前网站只把转录发给 Messages API，由固定模板执行 JSON，无法检查人脸遮挡。新流程使用本机 Claude Code CLI，固定模型 `claude-opus-5-5`，不自动降级。

1. 继续使用已有火山主、腾讯备用 ASR 和上传、批注、下载。
2. 计划阶段启动 Claude Code，加载项目视频剪辑 skill，使用 MCP 工具探测素材、查看原片帧、编写剪辑工程并生成真实低清预览。短素材不强制五条 Shorts 或 CTA。
3. 人工确认预览或添加批注。导出阶段再次由 Claude Code 调用工具执行自己编写的工程，查看最终成片帧并修正。FFmpeg / HyperFrames 是工具，不再套用网站固定视觉模板。
4. 每轮独立工作目录，保留旧成片。媒体命令运行在无外网的 Bubblewrap 文件隔离环境，只有本轮工作目录可写。Claude Code 不加载全局 hooks/MCP，服务凭证不传入媒体命令。
5. 保留 CLI 事件、工具审计、模型标识、源码、字幕、预览、成片及视觉审查记录。后端独立检查输出文件、音视频流、同步、黑帧和实际抽帧审查证据；不能只信 agent 声称通过。

验证包括隔离边界与失败恢复测试、前端类型/构建，以及真实样例的有预算和超时限制的 Claude Code 会话。部署重启会中断当前 API 请求，待本地结果可审查后再取得确认。
