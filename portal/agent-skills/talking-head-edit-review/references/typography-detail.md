# 排版细节审计

整帧只能判断层级和位置；字形、描边、阴影和字体气质必须看原始分辨率区域裁切。

## 必须检查的区域

- 标题带：通常取顶部 `y=0..0.22`，保留左右边缘和上下 padding。
- 身份区：按参考位置取右中区域，例如 `x=0.45..1, y=0.35..0.8`。
- 字幕区：通常取 `y=0.70..1`，保留字幕底板边缘和下一层安全区。
- 小型 badge、logo、进度条：围绕实际图形单独裁切。

使用 `view_frame_region` 时优先 `scale=2` 或 `scale=3`，所有待比较视频使用相同的归一化区域和相同的输出缩放。不要把整帧缩小后观察出的边缘当成描边宽度。

## 标题

逐项比较：

- 字体骨架：字形是窄体、方体、圆体还是手写/展示体；横竖笔画是否等宽；转角是否有明显圆角。
- 字重：是否接近 Heavy/Black，还是 Bold；相同字号下字腔是否过宽。
- 字宽和字距：是否压缩、是否过松；同一行文字的横向占用宽度。
- 行高：两行标题之间的垂直间隔；主标题与副标题的字号比例。
- 描边：描边颜色、可见宽度、内外轮廓是否锐利；是否过粗吞掉字腔。
- 阴影：是否存在偏移、模糊、透明度；是否只在右下或四周扩散。
- 底板：颜色、透明度、高度、左右 padding、圆角和是否贴边。
- 对齐：居中、左对齐或右对齐；标题内容与画布安全区的关系。

## 身份卡

- 位置：画面纵向相对位置、右侧或左侧边缘的距离。
- 行数和层级：姓名/主张一行，说明多行；主行与说明字的字号及字重差。
- 文字色：金色、白色或混合；金色饱和度是否一致。
- 描边和阴影：小字上是否使用细描边，阴影是否过重。
- 底板：无底板浮字、半透明底板或完全不透明底板的区别。
- 密度：右侧视觉重量是否与参考一致；不能因为缺少内容就伪造信息。

## 字幕

- 字体骨架与字重：是否比标题明显更粗/更宽，是否与标题属于同一字体家族。
- 字号：相对画面高度的比例；英文、数字和中文字宽差异。
- 描边：可见宽度、黑描边锐度、是否出现彩色外描边。
- 底板：颜色、透明度、左右 padding、上下 padding、行内宽度和圆角。
- 行高和分组：单行/两行、短句节拍、是否出现孤字、是否把完整名词拆开。
- 关键词：是否有明确金色强调；强调是否只作用于关键词而不是整句。
- 安全区：离画面底部、人物胸口和画面边缘的距离。

## 评分方式

对 `captionsAndGraphics` 和 `loadAndStyle` 的细节分，至少给出：

1. 一个标题区域裁切证据；
2. 一个身份区或“身份区缺失”证据；
3. 一个字幕区域裁切证据；
4. 对字体、描边、底板、间距中至少三项的明确判断。

只有当字形骨架、字重、字宽、描边和底板在局部裁切中都接近时，才可给 4 分。只有位置接近但字体/描边/间距明显不同，最高给 3 分。字体或描边细节无法确认时，要写入 limitation，不能猜具体字体名称。
