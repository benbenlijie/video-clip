# 字幕自动校对设计

## 意图

减少 ASR 错字进入预览和成片。以样片中的“把烦做的”为例，现有流程会把火山 ASR 的结果直接交给 Claude Code，之后只检查 SRT 时间码，不验证字幕文字。

## 现状与约束

- Wayne 先调用火山或腾讯 ASR，再把 `transcript.json` 作为文本交给 Claude Code。
- Claude Code CLI 当前只接受文本或文本流；视频 MCP 提供文件读写、离线命令执行和画面抽帧，没有音频识别工具。因此 Claude Code 当前不能直接听 WAV。
- 项目已有 OpenChatCut 源码中的本地 Whisper.cpp 实现，但 Wayne portal 没有接入本地 ASR，也没有发现系统级 `whisper-cli`。
- 当前目标是免费使用，避免第二次付费云端识别；保留原始识别结果，不让模型静默编造或改写台词。
- 在 `ben-home-server` 上对提供的 113.6 秒样片做了 Whisper.cpp v1.9.2 CPU-only 实测：i7-10700K、8 线程、显式 `--no-gpu`。量化 `base-q5_1` 用时 7.21 秒、峰值 RSS 约 297 MiB；量化 `small-q5_1` 用时 20.73 秒、峰值 RSS 约 563 MiB。
- 与项目已有火山 ASR 文本比较（忽略空白和常见标点，不是人工金标准），base 字符错误率为 13.5%，small 为 5.4%。Small 将样片中的目标词识别为“繁琐的”，base 识别为“凡速的”。

## 目标

- 在原有 ASR 之后，用本地 Whisper.cpp 对同一段音频做第二遍识别。
- 让 Claude Code 在现有剪辑会话中对比原始转录和 Whisper 结果，产出带修改依据的校对稿，不额外启动一次 Claude API 会话。
- 将校对稿用于剪辑预览、字幕和正式导出；保留原始 ASR 结果与每处修改记录。
- 两份识别结果冲突且无法可靠判断时，标记待人工确认，不强行补词。
- 未安装本地识别器时，保留现有人工校对路径，不把未经双重识别的文本标记成自动校对完成。

## 不在范围内

- 不宣称 Claude Code 能直接感知或聆听音频。
- 不调用第二个付费云端 ASR。
- 不更改用户的视频、音轨或原始 ASR 结果。
- 不要求自动纠错后取消最终视频人工审阅。

## 方案比较与建议

1. **给 Claude 直接附加 WAV。** 本机 Claude Code CLI 和当前 MCP 输入并不支持音频；在现状下无法落地。
2. **本地 Whisper.cpp 二次识别，再由 Claude 对照校正。** 不产生每次识别费用，Claude 可以基于两份声学识别结果和语境自动处理明确错词；对无法判定的冲突保留人工确认。这最符合免费使用和自动化目标，建议采用。
3. **增加第二家云端 ASR。** 集成简单，但会增加按次费用，并再次上传用户音频，不符合当前免费使用目标。

## 建议设计

1. FFmpeg 提取一次 16 kHz 单声道 WAV 后，并行启动现有云端 ASR 路径和本地 Whisper.cpp 第二识别；云端内部仍按火山主通道、腾讯备用的既有顺序执行。CPU 默认使用 `small-q5_1`（约 190 MB 模型文件）；低内存或低优先级机器可选择 `base-q5_1`（约 60 MB）。实测机器为 8 核 16 线程、64 GiB 内存；目标部署若配置更低，需先做 CPU 实测。通过服务端配置指定 `whisper-cli` 与模型路径；运行器仅读取当前项目音频并写入当前项目目录，设置时长与资源上限，不访问网络。任一路结果都单独记录；本地 Whisper 不可用时，云端转录仍可进入人工校对路线。
2. 将原始 ASR、Whisper 第二结果和待校对区间交给现有 Claude Code 剪辑会话。Claude 输出校对后 transcript、按区间列出的修改、依据及 unresolved 列表。优先保留口语原意；不得只凭上下文补充录音中听不到的内容。
3. 服务端校验结果结构、时间戳和文本覆盖，保存 `transcript.original.json`、第二识别结果、校对结果和变更记录。原有 `transcript.json` / `.srt` 指向校对后的版本，使下游剪辑统一读取校对稿。
4. 明确且双识别支持的纠错自动应用；识别结果分歧或低可信区间在 UI 中逐项展示，可播放对应原音并人工确认。Claude Code 预览和最终渲染都使用同一份确认稿。
5. QC 对照校对稿与最终 SRT，拒绝缺失、额外或被改写的口播文本；时间码合法仍需字幕文字完整。
6. 本地 Whisper 不可用或模型缺失时，显示配置/安装提示并退回人工逐句校对；不能把普通 Claude 文本推理冒充听音纠错。

## 验收

- 单元/集成验证本地识别结果进入 Claude 校对输入、原稿不可覆盖、修订记录可追溯、冲突会被标为待确认。
- 验证 Claude 生成的 SRT 与已确认校对稿不一致时 QC 失败。
- 用本次样片验证“把烦做的”等差异能进入校对结果；未再次调用火山、腾讯或新增 Claude API 会话。
- 最终字幕仍需人工完整观看/听审；模型自动校对不等同于准确率保证。

## 待确认

此设计将“Claude 自动听音”实现为“本地 Whisper 从音频产生第二份识别证据，Claude 自动对照并校正”。Claude Code 本身不直接听音。Small 模型在这条样片上比 base 多用约 13.5 秒和 266 MiB 峰值内存，但识别结果明显更接近已有火山转录，且正确识别目标词；据此建议默认 small。错误率对比只说明两份 ASR 的相对差异，不能替代人工核对。
